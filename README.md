# 一切献给虎破王（All for Hupowang）

一款 **2D 节奏 Roguelike** 独立游戏，使用团结引擎（Tuanjie / Unity 中国版）制作。

## 下载

前往本仓库的 **Releases** 页面，下载最新版本压缩包 `一切献给虎破王.zip`：

1. 下载 zip 并完整解压到任意目录；
2. 双击运行 `My project.exe` 开始游戏。

> 目前仅提供 **Windows 64 位** 版本。

## 系统要求

- 操作系统：Windows 10 / 11（64 位）
- 显卡：支持 DirectX 11
- 存储：约 1.6 GB 可用空间（解压后）

## 操作说明

（以下为常见默认按键，最终以游戏内提示为准，部分按键可在设置中调整）

- 移动：方向键 / WASD
- 普通攻击、特攻、防御：见游戏内按键提示

## 关于

- 引擎：团结引擎（Tuanjie）
- 类型：2D 节奏 Roguelike
- 平台：Windows x64

## 注意事项

- 未签名的可执行文件可能触发 Windows SmartScreen 提示「未知发布者」，点击「更多信息 → 仍要运行」即可。
- 请**完整解压**后再运行，不要直接在压缩包内双击 exe。
