# 一切献给虎破王（All for Hupowang）

一款 **2D 节奏 Roguelike** 独立游戏，使用团结引擎（Tuanjie / Unity 中国版）制作。

## 下载

前往本仓库的 **Releases** 页面，下载最新版本的压缩包（`.zip`，例如 `all-for-hupowang-v0.1.0.zip`），然后：

1. 把 zip **完整解压** 到任意目录；
2. 双击运行 `My project.exe` 开始游戏。

> 目前仅提供 **Windows 64 位** 版本。

## 系统要求

- 操作系统：Windows 10 / 11（64 位）
- 显卡：支持 DirectX 11
- 存储：约 1.6 GB 可用空间（解压后）

## 操作说明

默认按键如下，均可在「设置 → 按键绑定」中修改。

| 操作 | 默认按键 | 说明 |
| --- | --- | --- |
| 左移 | `A` / `←` | 向左移动一格（跟随节拍） |
| 右移 | `D` / `→` | 向右移动一格（跟随节拍） |
| 向左攻击 | `J` | 向左侧普攻（近战） |
| 向右攻击 | `L` | 向右侧普攻（近战） |
| 特攻 | `I` | 释放特攻，效果随所选武器（马头 / 虎威）不同 |
| 技能 · 光速时间 | `O` | 激活技能「光速时间」 |
| 防御 / 格挡 | `K` | 举盾格挡（护盾需通关第 1 段主线 BOSS 后解锁） |
| 使用血瓶 | `U` | 消耗血瓶回复生命 |
| 交互 | `空格` | 与 NPC、传送门、奖励点等交互 |
| 切换镜头方向 | `Tab` | 左右切换镜头视角 |
| 查看图鉴 | `R` | 打开怪物图鉴 / 详情 |

对话与界面通用按键：

- `空格` / `回车`：剧情对话、幻灯片继续
- `Esc`：关闭面板 / 返回
- 菜单与按钮：可用鼠标点击操作

> 注：移动为 **左右两向**（横向格子），不是上下四向。

## 关于

- 引擎：团结引擎（Tuanjie）
- 类型：2D 节奏 Roguelike
- 平台：Windows x64

## 注意事项

- 未签名的可执行文件可能触发 Windows SmartScreen 提示「未知发布者」，点击「更多信息 → 仍要运行」即可。
- 请**完整解压**后再运行，不要直接在压缩包内双击 exe。
